# EventQR Suite

> Cryptographically-signed QR tickets and gate-side scanning — without a server.

## What's bundled

- **HMAC-signed tickets** — every QR carries a signature only your scanner can verify, blocking ticket forgery.
- **Expiring tickets** — set a deadline; expired tickets are rejected automatically.
- **One-time-use codes** — each ticket has a unique nonce so duplicates can be detected.
- **Built-in scanner** — the existing scanner page is repurposed as the gate check-in screen, with on-screen validation feedback.
- **Bulk ticket generator** — feed in a CSV of attendee names, get a ZIP of personalised QR PNGs back.
- **Event-themed templates** — high-contrast for fast scanning, plus a corporate conference badge style.
