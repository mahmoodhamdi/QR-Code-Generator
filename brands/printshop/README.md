# PrintShopQR

> Bulk QR generation built for production print shops.

## What's bundled

- **CSV → 1000+ QR codes** in seconds. Each row can have its own URL, color, and logo.
- **Print-ready output**: 300 / 600 / 1200 DPI, bleed margins (3 or 5 mm), crop marks, CMYK conversion note baked into the PDF.
- **Per-row customisation** — different colors, patterns, and corner styles in one batch.
- **Output formats**: ZIP of PNGs + manifest CSV, single multi-page PDF, or A4 sheet with multiple QRs.
- **Templates** — high error-correction product label, compact shipping label.

- One CSV upload replaces 1,000 manual generations.
