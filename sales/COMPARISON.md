# Competitive Comparison

How each vertical compares to the alternatives a buyer is likely already considering.

## vs. QR Code Monkey (free)

| Capability | QR Code Monkey | Our Verticals |
| --- | --- | --- |
| QR types | 7 | 12 |
| Bulk generation | No | Yes (CSV → 1000+) |
| Print-ready PDF (CMYK + bleed + crop marks) | No | Yes |
| Dynamic QR + analytics | No | Yes (MarketingQR) |
| Signed / expiring tickets | No | Yes (EventQR) |
| Templates library | 8 | 20+ |
| Brand kit save/load | No | Yes |
| Self-hosted | No (their site only) | Yes (Docker) |
| Bilingual UI (EN + AR) | English only | EN + AR + FR + ES + PT + DE + TR |
| Source code | No | Yes |

**Verdict:** QR Code Monkey is free, but every feature gap above is a reason a serious user upgrades.

## vs. competing source-code marketplaces (CodeCanyon)

CodeCanyon listings for QR generators range from $19 to $79. They're typically:

- jQuery-era code (5+ years old)
- No tests
- No vertical-specific positioning
- Cheap, but you get what you pay for

We're 10x to 50x more expensive, but we're modern (Next.js 16, React 19, TypeScript strict), tested, and the vertical packaging is the differentiator that makes the price justifiable.
